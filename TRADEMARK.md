# Trademark and Branding Rules: Idiot Box

**Owner:** The Wonderland Studio
**Applies to:** the names **"Idiot Box"** and **"The Wonderland Studio"**, the Idiot Box logo and icons, and any other visual identity of the project (together: the **Marks**).

This document is about **names and branding only**. It does not limit any copyright freedom the GPL-3.0 gives you. You can still view, fork, modify and share the code under that license. These rules only cover how you may use our names and logos while doing so. If any rule here ever conflicts with the GPL, the GPL wins for copyright; this file keeps applying to trademarks.

## The basic idea

If people see the name Idiot Box, they should be looking at the real thing, made by us. Anything else must clearly say it is unofficial.

## Always allowed (no permission needed)

1. **Talking about the software.** You can use the name "Idiot Box" to describe it truthfully in articles, reviews, tutorials, videos, and in a fork's README ("a fork of Idiot Box", with a link to https://github.com/TheWonderlandStudio/Idiot_Box).
2. **Unmodified copies.** If you share the software exactly as we released it, keep the names, logo, copyright and license notices exactly as they are.
3. **Contributing back.** Pull requests, issues and forks made to contribute to the official project may use the Marks for that purpose.

## Modified versions and forks

If you change the software and share your version publicly:

1. **Say it is unofficial, up front.** Your app title, about screen, README and any store listing must make clear it is not the official Idiot Box, for example: *"MyEditor, based on Idiot Box by The Wonderland Studio (unofficial fork)"* with a link to the official repository.
2. **Give credit.** Keep all existing copyright and license notices intact, and keep a visible credit line naming Idiot Box and The Wonderland Studio with a link to the official repository. Do not remove or hide attribution.
3. **Do not present it as official.** Nothing in your fork (name, icon, screenshots, description, domain) may suggest it is endorsed by, affiliated with, or the same product as the official Idiot Box.

## Never allowed without written permission

1. **Repackaging the same app under a different name.** Taking Idiot Box essentially as-is, renaming it, and publishing it as if it were your own product.
2. **Using our Marks on something else.** Putting "Idiot Box", "The Wonderland Studio", our logo or confusingly similar names or icons on unrelated software, websites, domains or merchandise.
3. **Removing or hiding credit.** Stripping copyright notices, license files, attribution lines or the about information to make the work look like it has no origin.
4. **Implying endorsement.** Stating or suggesting that we sponsor, approve or are connected with your fork, unless we have said so in writing.

## Logo

The Idiot Box logo and icons may be used only with unmodified official releases, or with prior written permission. Forks and modified versions must use their own distinct visual identity.

## Permission and contact

Want to use a Mark in a way this file does not allow? Ask first. Open an issue at https://github.com/TheWonderlandStudio/Idiot_Box describing exactly what you want to do. Permission, when given, is specific, revocable, and in writing.

## Enforcement

If these rules are broken, we may ask for correction first. Continued misuse after notice can lead to a demand to stop using the Marks and, where needed, formal trademark or platform complaints. Nothing here affects anyone's rights under the GPL-3.0 copyright license.
