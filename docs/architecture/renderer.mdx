# Renderer

The renderer is React 19 (`electron/renderer/index.jsx`) bundled by esbuild into `bundle.js` (IIFE) with lazy chunks for heavy panels. Layout is **FlexLayout** (drag, split, float tabs); the titlebar is `custom-electron-titlebar`; the CSP lives in a meta tag (see [Security & privacy](security-privacy.mdx)).

## Lazy chunks

esbuild emits on-demand IIFE chunks (`globalName __ibx_chunk_<name>`) to `electron/renderer/chunks/`, with React shared from the main bundle: `canvas`, `ai-agent` (OpenCode), `notebook`, `git`, `community`, `android`, `desktop`, `excalidraw` (OpenPencil). Panels only cost startup time when first opened.

## Settings window

`settings-entry.jsx` → `settings-bundle.js` (separate esbuild step) renders `SettingsWindow` with pages: General, Appearance, Editor, Terminal, Git, Hub, Preview, Canvas, Keybindings, Extensions. Appearance reads the generated theme-token registry from `theme/tokens.generated.js`.

## Styling

- `layout.css`, `responsive.css`, `variables.css` (the design-token sheet), `settings.css`, plus per-feature CSS files.
- Theme tokens: CSS variables for dark/light, generated into a JS registry at build time (`npm run build:theme`) — the Settings Appearance picker edits these tokens.
- `ai-elements/ai-tw-css.js` is generated scoped Tailwind CSS injected into Shadow DOM for the AI chat UI.

## Compat shims

The editor keeps legacy Monaco compatibility (`ensureMonacoReady` resolves immediately, a `monaco:ready` event fires alongside `codemirror:ready`, and `MonacoEditorPanel` is re-exported as an alias) — the actual engine is CodeMirror 6. Monaco survives only as an unused vendor bundle on the landing page.
