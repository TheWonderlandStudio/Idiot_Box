# Notebooks

The Notebook panel executes Python notebooks (.ipynb-style cells) against your local Python.

- **Check Python** (`notebook:checkPython`) verifies a Python interpreter is available.
- **Execute** (`notebook:execute`) runs the notebook and streams output back into the cells.
- **Restart** (`notebook:restart`) resets the kernel session between runs.

The backend uses the same Python detection as the debugger (`python` → `py -3`). For debugging Python code step-by-step, see [Debugger](debugger.mdx); for running plain scripts, see [Terminal & Run](terminal-run.mdx).
