# First steps

## Open a project

- **Ctrl+O** (Open Project) or the Project Hub's **Open Folder** button picks a folder.
- **Ctrl+N** (New Project) creates or selects a project folder.
- **Ctrl+Shift+O** opens a single file without a project.
- Recent projects and pinned projects appear on the [Project Hub](../user-guide/project-hub.mdx); the Windows jump list also shows recent projects.

Everything is panel-based: the editor, terminal, Git, browser, output, problems, and more are tabs in a draggable FlexLayout. Drag any tab to the border of another pane to split, to the center to nest, or float it as a window.

## Editor tabs

- **Ctrl+T** new tab, **Ctrl+W** close tab, **Ctrl+Shift+T** reopen the last closed tab, **Ctrl+Tab** / **Ctrl+Shift+Tab** cycle tabs.
- **Ctrl+\\** splits the editor right. Pinned tabs stay across project switches (via **Pin** in the tab context menu).
- Unsaved files show a dirty marker; closing asks to save. Auto Save is available in **File → Auto Save**.

## Search & commands

- **Ctrl+Shift+P** — Command Palette: every app command, plus recent files.
- **Ctrl+P** — Quick Open: jump to a file or command.
- **Ctrl+Shift+F** / **Ctrl+Shift+H** — project-wide find / replace.
- **Ctrl+Alt+H** — Local History for the current file.

## Windows & layout

- The main window is 1280×720 by default; bounds, zoom, and panel layout are restored on the next launch.
- **View → Reset Layout** (Ctrl+Alt+R) restores the default panel arrangement; **Layout Presets** let you save/restore your own arrangements.
- **Ctrl+**, opens Settings; zoom lives in **View → Zoom In/Out/Reset** (0.25×–3.0×, 0.1 steps).

## Settings

The Settings window covers General, Appearance, Editor, Terminal, Git, Hub, Preview, Canvas, Keybindings, and Extensions — see [Settings](../user-guide/settings.mdx).
