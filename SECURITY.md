# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| Latest release (0.1.x) | Yes |
| Older releases | No — please update first |

## Reporting a vulnerability

**Do not open a public issue for security problems.** Instead, use **private vulnerability reporting**:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability** and describe the issue, steps to reproduce, and the versions affected.

We will acknowledge your report, investigate, and keep you updated. If the issue is confirmed, we will fix it and credit you in the release notes (unless you prefer to stay anonymous).

## Scope

Idiot Box is a local-first desktop app: your code, settings, API keys and chat history stay on your machine. Reports about the app exfiltrating data, executing untrusted content, insecure IPC/preload bridges, auto-update tampering, or installer integrity are in scope and appreciated.

Out of scope: the landing page's third-party CDNs, social engineering, and bugs without a security impact (file those as normal issues).
